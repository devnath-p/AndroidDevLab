# Experiment 1 – Hello World Android Application

## Aim

To develop a simple Android application using Kotlin that displays a **"Hello World!"** message along with the student's name and USN.

---

## Concept

Android applications are built using **Activities** and **XML layouts**. An Activity acts as the entry point of the application, while XML is used to design the user interface. In this experiment, a `TextView` is used to display a greeting message and student information.

---

## Scenario

A simple Android application is developed to verify the Android development environment and demonstrate the basic structure of an Android project. When the application is launched, it displays:

- Hello World!
- Student Name
- Student USN

---

## Technologies Used

- Kotlin
- Android Studio
- XML
- Android SDK
